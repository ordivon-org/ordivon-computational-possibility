## When CP is deletion-essential

Use CP when the operation needs at least one of these distinctions.

### Situation Analysis

Question: **What exactly is the computational claim?**

Use it when source meaning is available but the computational obligation may still be underconstituted across quantifiers, information/revelation, witness grammar, interaction/process, resource semantics or target scope.

Key outcome:

`UNDERCONSTITUTED != Impossible`.

### Local Possibility Analysis

Question: **What is computationally possible in this constituted situation?**

Use it for exact-scope achievability/impossibility, resource-constrained feasibility, complexity/frontiers, approximation/probability-sensitive feasibility and lower-bound scope discipline.

### Comparative / Transport Analysis

Question: **What computational consequence survives when representation, provider, capability, regime, resource or context changes?**

Use it for reduction/simulation, provider or tool substitution, composition, comparative power, theorem variance, resource overhead/reflection and semantic-versus-computational preservation boundaries.

Key controls include:

- `SameAPI != SameComputationalCapability`;
- `SemanticEquivalence != ComputationalEquivalence`;
- `ComponentwiseAchievability != CompositionalAchievability`;
- `ValidOutputRelation != SelectionSemantics`;
- `PointwiseValidity != HistoryValidity`;
- `PerCallMarginals != JointLaw`.

### Applicability Analysis

Question: **What does a formal computational result license us to say about this actual owner-scoped target now?**

Use `ClaimScope + TargetScope + TransportBurden + PremiseEvidence + Verdict` and preserve the directional asymmetry:

- constructive / upper: formal witness -> actual witness, plus upper domination where quantitative;
- impossibility / lower: relevant actual candidate -> formal witness, plus lower reflection/coverage where quantitative.

Key controls:

- `HistoricalCapability != CurrentCapability`;
- `OneSuccessfulRun != UniformFamilyAchievability`;
- `OneRouteFailure != ActualCandidateCoverage`;
- `SchemaValid != TheoremTrue`.
